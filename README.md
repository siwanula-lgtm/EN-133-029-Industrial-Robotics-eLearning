เว็บไซต์สื่อการสอนออนไลน์ของรายวิชา EN-133-029 หุ่นยนต์อุตสาหกรรม 9 หน่วยเรียน
เนื้อหาทั้งหมดนำมาจาก **เอกสารประกอบการสอน EN-133-029 ฉบับสมบูรณ์ R13** ได้แก่ ใบความรู้ แผนการจัดการเรียนรู้
ใบงานปฏิบัติ แบบฝึกหัดท้ายหน่วยพร้อมเฉลย แบบทดสอบก่อนเรียน/หลังเรียน และข้อมูลรายวิชา
โครงเว็บใช้ template จาก [EN-012-314-AI](https://github.com/babankbro/EN-012-314-AI)

## รันด้วย Docker (แนะนำ)

ต้องติดตั้ง [Docker Desktop](https://www.docker.com/products/docker-desktop/) ก่อน แล้วเปิด Terminal / PowerShell ในโฟลเดอร์นี้

```bash
docker compose up -d --build     # build และเปิดเว็บ → http://localhost:8030
docker compose logs -f           # ดู log
docker compose down              # หยุดเว็บ
```

แก้เนื้อหาใน `content/` แล้วสั่ง `docker compose up -d --build` อีกครั้งเพื่อ build ใหม่

หากไม่ใช้ compose:

```bash
docker build -t en-133-029-robotics-elearning .
docker run -d -p 8030:3000 --name robotics-elearning en-133-029-robotics-elearning
```

## รันด้วย Node.js (สำหรับแก้ไขเนื้อหา)

ต้องใช้ Node.js 18.17 ขึ้นไป (แนะนำ 20)

```bash
npm install
npm run dev          # เปิด http://localhost:8030 (แก้ไฟล์แล้วรีเฟรชได้ทันที)
npm run check        # ตรวจความครบถ้วนและรูปแบบของเนื้อหา
npm run build && npm start
```

## สถิติการเข้าใช้เว็บไซต์

เว็บไซต์นับสถิติการเข้าใช้เองบนเครื่องแม่ข่าย (ไม่ใช้บริการภายนอก ไม่เก็บ IP หรือข้อมูลระบุตัวบุคคล ไม่นับ Bot)

- กล่องสถิติแสดงที่แถบเมนูด้านซ้ายและหน้าแรก: ผู้เข้าใช้วันนี้ เมื่อวาน เดือนนี้ ทั้งหมด จำนวนการเข้าใช้ จำนวนการเปิดหน้า และผู้ที่กำลังออนไลน์
- หน้า `/stats` เป็นรายงานฉบับเต็ม: สรุปตามช่วงเวลา กราฟ 30 วัน สถิติรายเดือน รายหน่วยเรียน (ใบความรู้/แผน/ใบงาน/ก่อน-หลังเรียน) หมวดเนื้อหา อุปกรณ์ และหน้ายอดนิยม พร้อมปุ่มพิมพ์/บันทึก PDF
- ส่งออก CSV สำหรับรายงานผลการใช้สื่อ: `/api/stats?format=csv&type=daily` (รายวัน), `type=monthly` (รายเดือน), `type=pages` (รายหน้า)
- นิยาม: ผู้เข้าใช้ = อุปกรณ์ไม่ซ้ำต่อวัน · การเข้าใช้ = 1 ครั้ง สิ้นสุดเมื่อไม่ใช้งานเกิน 30 นาที · การเปิดหน้า = จำนวนครั้งที่เปิดหน้าเว็บ
- ข้อมูลเก็บใน Docker volume `visitor-stats` (ไฟล์ `/app/data/visitor-stats.json`) จึงไม่หายเมื่อ build ใหม่หรือรีสตาร์ต
  - สำรองข้อมูล: `docker cp en-133-029-robotics-elearning:/app/data/visitor-stats.json .`
  - ห้ามสั่ง `docker compose down -v` เพราะ `-v` จะลบข้อมูลสถิติ

### สถิติการเข้าใช้บน Vercel

Vercel เป็นระบบ serverless ที่ไม่มีดิสก์ถาวร จึงต้องเก็บสถิติในฐานข้อมูล Redis (ฟรี) — ทำครั้งเดียวต่อโปรเจกต์:

1. เปิดโปรเจกต์บน vercel.com → แท็บ **Storage** → **Create Database / Connect** → เลือก **Upstash for Redis** (แผนฟรี) → Connect กับโปรเจกต์นี้
   (ใช้ฐานข้อมูลเดียวร่วมกันหลายรายวิชาได้ เพราะแต่ละวิชาแยกคีย์ด้วยรหัสวิชา)
2. ระบบจะเพิ่มตัวแปร `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้อัตโนมัติ (หรือ `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`)
3. กด **Redeploy** หนึ่งครั้ง — กล่องสถิติจะเริ่มนับทันที

ก่อนเชื่อมฐานข้อมูล หน้าเว็บจะแสดงข้อความ “ยังไม่ได้เชื่อมต่อฐานข้อมูลสถิติ” และจะไม่บันทึกตัวเลข (เพื่อไม่ให้ได้ตัวเลขผิด)

## โครงสร้างโปรเจกต์

```
├── app/
│   ├── page.tsx                  ← หน้าหลัก (ภาพรวมรายวิชา + CLO)
│   ├── course-info/page.tsx      ← ข้อมูลรายวิชา (content/course-info.md)
│   ├── module/[id]/page.tsx      ← ใบความรู้ + จุดประสงค์ + แบบฝึกหัดพร้อมเฉลย
│   ├── plan/[id]/page.tsx        ← แผนการจัดการเรียนรู้ประจำหน่วย
│   ├── lab/[id]/page.tsx         ← ใบงานปฏิบัติ (พิมพ์/บันทึก PDF ได้)
│   ├── exam/[kind]/[id]/page.tsx ← แบบทดสอบก่อนเรียน (pre) / หลังเรียน (post)
│   └── api/content/[...path]/    ← ให้บริการไฟล์ใน content/ (Review Sheet)
├── components/                   ← Header, Sidebar, MarkdownContent, ExamClient, PrintButton ฯลฯ
├── lib/
│   ├── course.ts                 ← ข้อมูลรายวิชาและ CLOs
│   ├── modules-data.ts           ← ข้อมูล 9 หน่วย (สัปดาห์ ชั่วโมง ท/ป CLO หัวข้อ)
│   ├── exam-types.ts             ← ชนิดข้อมูลแบบทดสอบ
│   └── content.ts                ← อ่าน markdown / exam JSON
├── content/
│   ├── course-info.md            ← ข้อมูลรายวิชา
│   ├── modules/module-XX.md      ← ใบความรู้
│   ├── plans/plan-XX.md          ← แผนการจัดการเรียนรู้
│   ├── labs/lab-XX.md            ← ใบงานปฏิบัติ
│   ├── exams/pre-XX.json         ← แบบทดสอบก่อนเรียน 10 ข้อ
│   ├── exams/post-XX.json        ← แบบทดสอบหลังเรียน 10 ข้อ
│   └── SHEET/review_sheet_XX.html← แบบทบทวน 1 หน้า A4
├── public/images/book/           ← รูปประกอบจากเอกสารประกอบการสอน
├── Dockerfile · docker-compose.yml
└── CONTENT_GUIDE.md              ← คู่มือแก้ไขเนื้อหา
```

## ฟีเจอร์

- **Docs-style Layout** — Sidebar + Content, Dark/Light Mode, ค้นหา (Ctrl+K), Responsive
- **ใบความรู้** พร้อมรูปประกอบ ตาราง จุดประสงค์การสอน แบบฝึกหัดท้ายหน่วย (กดดูเฉลยได้) และบรรณานุกรม APA 7
- **แผนการจัดการเรียนรู้** และ **ใบงานปฏิบัติ** — พิมพ์หรือบันทึกเป็น PDF ได้
- **แบบทดสอบก่อนเรียน/หลังเรียน** หน่วยละ 10 ข้อ 5 ตัวเลือก จับเวลา ตรวจอัตโนมัติ แสดงเฉลย และพิมพ์ผลได้ (เกณฑ์ผ่านร้อยละ 50)
- **Review Sheet** สรุป 1 หน้า A4 ต่อหน่วย
