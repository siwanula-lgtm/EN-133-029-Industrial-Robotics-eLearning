EN-133-029 Industrial Robotics · Sequential Control Programming and Sensors for Robots

📌 1. สาระสำคัญ

การเขียนโปรแกรมควบคุมหุ่นยนต์แบบลำดับขั้น (Sequential Control) เป็นพื้นฐานสำคัญของการใช้งานหุ่นยนต์อุตสาหกรรม โดยกำหนดให้หุ่นยนต์ทำงาน ตามขั้นตอนที่แน่นอนซ้ำกันในแต่ละรอบการทำงาน (Work Cycle) ตั้งแต่ระบบควบคุมอย่างง่าย (Limited Sequence Control) ไปจนถึงระบบที่บันทึกตำแหน่ง แบบจุดต่อจุด (Playback PTP) และแบบเส้นทางต่อเนื่อง (Playback CP) การโปรแกรมทำได้หลายวิธี ตั้งแต่การสอนงานด้วยแผงสอนงาน (Teach Pendant) ไปจนถึงการเขียนโค้ดด้วยภาษาโปรแกรมเฉพาะของหุ่นยนต์ ซึ่งสามารถรับสัญญาณจากเซนเซอร์ภายนอก (External Sensor) เช่น …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 3.1 เข้าใจระบบควบคุมและวิธีการโปรแกรมหุ่นยนต์ได้
  • 3.2 เข้าใจคำสั่งพื้นฐานและเซนเซอร์สำหรับหุ่นยนต์ได้
  • 3.3 เข้าใจการเขียนโปรแกรมแบบมีเงื่อนไขและโปรแกรมย่อยได้
  • 3.4 ปฏิบัติการตรวจสอบจลนศาสตร์ตรงของแขนกล 2-DOF ด้วย ESP32
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 3.1 ระบบควบคุมและวิธีการโปรแกรมหุ่นยนต์
  • 3.2 คำสั่งพื้นฐานและเซนเซอร์สำหรับหุ่นยนต์
  • 3.3 การเขียนโปรแกรมแบบมีเงื่อนไขและโปรแกรมย่อย
  • 3.4 การเขียนโปรแกรมควบคุมแบบลำดับขั้นร่วมกับเซนเซอร์
📝 4. บทสรุป

ระบบควบคุมหุ่นยนต์แบ่งได้หลายประเภทตามลักษณะการควบคุมเส้นทาง การโปรแกรมหุ่นยนต์ทำได้ทั้งแบบใช้แผงสอนงานและแบบออฟไลน์ โดยมีคำสั่งพื้นฐานสำหรับการเคลื่อนที่และการควบคุมอุปกรณ์ปลายแขน เซนเซอร์ช่วยให้หุ่นยนต์รับรู้สภาพแวดล้อมและชิ้นงาน การเขียนโปรแกรมแบบมีเงื่อนไขร่วมกับสัญญาณเซนเซอร์ โปรแกรมย่อย และตัวนับจำนวนรอบ ทำให้หุ่นยนต์ทำงานแบบลำดับขั้นได้อย่างถูกต้องและยืดหยุ่น

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงเปรียบเทียบความแตกต่างระหว่างระบบควบคุมแบบ Limited Sequence Control กับ Playback Point-to-Point (PTP)
  • เพราะเหตุใดวิธี Off-line Programming จึงได้รับความนิยมเพิ่มขึ้นในโรงงานอุตสาหกรรมปัจจุบัน
  • เพราะเหตุใดผู้ใช้งานระดับ Operator จึงไม่จำเป็นต้องใช้รหัสผ่านในการใช้งาน Teach Pendant แต่ผู้ใช้งานระดับ …
  • จงเขียนคำสั่งสั้น ๆ เพื่อสั่งให้หุ่นยนต์เคลื่อนที่ไปยังตำแหน่ง P3 ตามแนวเส้นตรง ด้วยความเร็วโดยรวม 60%
  • จงยกตัวอย่างเซนเซอร์ภายนอก (External Sensor) 3 ชนิด พร้อมลักษณะการใช้งานของแต่ละชนิด
  • จากคำสั่ง "DEF IO SENSOR1 = BIT,1" และ "IF SENSOR1 = 1 THEN GOTO PICK ELSE GOTO WAIT" …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • รับชุดฝึก ตรวจความพร้อมของอุปกรณ์ตามรายการ และอ่านข้อควรระวังด้านความปลอดภัยร่วมกับครูผู้สอน
  • เตรียมความพร้อมและปฏิบัติตามข้อควรระวังด้านความปลอดภัย
