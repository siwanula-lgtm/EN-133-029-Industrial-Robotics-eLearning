📡 Review Sheet หน่วยที่ 4 — การเขียนโปรแกรมควบคุมแบบต่อเนื่อง
EN-133-029 Industrial Robotics · Continuous Path Control Programming
สัปดาห์ที่ 5–6 · ท 4 / ป 4 ชม. · CLO2, CLO3, CLO4
ใบงานปฏิบัติ 2 ใบงาน
📌 1. สาระสำคัญ

การควบคุมแบบต่อเนื่อง (Continuous Path Control: CP) เป็นการเคลื่อนที่ของหุ่นยนต์ผ่านหลายตำแหน่งอย่างต่อเนื่องโดยไม่หยุดกะทันหันระหว่างทาง แตกต่างจากการควบคุมแบบจุดต่อจุด (Point-to-Point) ที่เน้นความแม่นยำ ณ ตำแหน่งปลายทางเป็นหลัก การเขียนโปรแกรมควบคุมแบบต่อเนื่องอาศัยการเรียงคำสั่ง เคลื่อนที่แบบเส้นตรง (MVS) ต่อกันหลายจุด ร่วมกับการคำนวณตำแหน่งด้วยตัวแปรเวกเตอร์ (Vector Function) ซึ่งช่วยให้กำหนดตำแหน่งใหม่จากตำแหน่งเดิม บวกกับระยะเลื่อนหรือมุมหมุนที่ต้องการได้อย่างยืดหยุ่น …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 4.1 นำความรู้หลักการควบคุมแบบต่อเนื่องและการโปรแกรมตำแหน่งไปใช้ได้
  • 4.2 ปฏิบัติการเปรียบเทียบการเคลื่อนที่แบบจุดต่อจุดกับแบบต่อเนื่องด้วยแขนกล 2-DOF
  • 4.3 นำความรู้หลักการเขียนโปรแกรมแบบพาเลทและการควบคุมจังหวะเวลาไปใช้ได้
  • 4.4 ปฏิบัติการเขียนโปรแกรมจัดเรียงชิ้นงานแบบพาเลทด้วย ESP32 ได้ถูกต้องและปลอดภัย
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 4.1 การควบคุมแบบต่อเนื่องและการโปรแกรมตำแหน่ง
  • 4.2 การเปรียบเทียบการเคลื่อนที่แบบจุดต่อจุดกับแบบต่อเนื่อง
  • 4.3 การเขียนโปรแกรมแบบพาเลทและการควบคุมจังหวะเวลา
  • 4.4 การเขียนโปรแกรมจัดเรียงชิ้นงานแบบพาเลท
📝 4. บทสรุป

การควบคุมแบบต่อเนื่องทำให้ปลายแขนหุ่นยนต์เคลื่อนที่ตามเส้นทางที่กำหนดอย่างราบรื่น โดยใช้คำสั่งเคลื่อนที่แบบเส้นตรงต่อกันหลายจุด ตัวแปรเวกเตอร์สำหรับกำหนดตำแหน่ง และเวกเตอร์การหมุนสำหรับปรับทิศทางปลายแขน การเขียนโปรแกรมแบบพาเลทร่วมกับลูป FOR...NEXT ช่วยให้หุ่นยนต์จัดเรียงชิ้นงานหลายตำแหน่งได้ด้วยโปรแกรมที่กระชับ และการควบคุมความเร็วและจังหวะเวลาช่วยกำหนดรอบเวลาการทำงานให้เหมาะสมกับกระบวนการผลิต

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงยกตัวอย่างงานอุตสาหกรรม 2 ประเภทที่เหมาะกับการควบคุมแบบ PTP และ 2 ประเภทที่เหมาะกับการควบคุมแบบ CP …
  • เพราะเหตุใดการเขียนคำสั่ง MVS ต่อกันหลายจุดโดยไม่แทรกคำสั่ง DLY จึงสร้างเส้นทางต่อเนื่องได้ ในขณะที่หากแทรก …
  • จงเขียนคำสั่งกำหนดตำแหน่งใหม่ชื่อ TARGET_POS จากตำแหน่งอ้างอิง P50 โดยให้ยกขึ้นตามแกน Z 80 หน่วย
  • เพราะเหตุใดในงานเชื่อมตะเข็บโค้ง จึงจำเป็นต้องใช้เวกเตอร์การหมุน (Orientation Vector) ร่วมกับเวกเตอร์ตำแหน่ง …
  • จงอธิบายความหมายของพารามิเตอร์แต่ละตัวในคำสั่ง DEF PLT 1,P4,P8,P9,P10,4,2,1
  • เพราะเหตุใดรูปแบบ Zig-Zag จึงมักใช้ระยะทางการเคลื่อนที่รวมน้อยกว่ารูปแบบ Same Direction …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • รับชุดฝึก ตรวจความพร้อมของอุปกรณ์ตามรายการ และอ่านข้อควรระวังด้านความปลอดภัยร่วมกับครูผู้สอน
  • เตรียมความพร้อมและปฏิบัติตามข้อควรระวังด้านความปลอดภัย
