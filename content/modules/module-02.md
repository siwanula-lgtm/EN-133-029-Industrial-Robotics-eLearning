## 2.1 จลนศาสตร์ของหุ่นยนต์

### 2.1.1 จลนศาสตร์ตรง (Forward Kinematics)

จลนศาสตร์ (Kinematics) เป็นการศึกษาความสัมพันธ์ระหว่างตำแหน่งของข้อต่อ (Joint
Variables) กับตำแหน่งและทิศทางของปลายแขนหุ่นยนต์
โดยไม่พิจารณาแรงหรือแรงบิดที่ทำให้เกิดการเคลื่อนที่ จลนศาสตร์ตรง (Forward Kinematics:
FK) คือการคำนวณตำแหน่ง (Position) และทิศทาง (Orientation)
ของปลายแขนจากค่ามุมข้อต่อ (สำหรับ Revolute Joint) หรือระยะเลื่อน (สำหรับ
Prismatic Joint) ที่ทราบอยู่แล้ว ลักษณะเด่นของปัญหา FK คือมีคำตอบเพียงชุดเดียวเสมอ
(Unique Solution) เพราะเมื่อกำหนดมุมข้อต่อทุกข้อแน่นอนแล้ว
ตำแหน่งปลายแขนย่อมถูกกำหนดตามไปด้วย

ตัวอย่างที่ใช้อธิบายหลักการได้ชัดเจนที่สุดคือแขนกลระนาบ 2 ท่อน (2-Link Planar Arm)
ซึ่งเคลื่อนที่อยู่ในระนาบ X-Y เดียว ประกอบด้วยท่อนแขนความยาว L1 และ L2
เชื่อมต่อกันด้วยข้อต่อหมุน 2 ข้อที่มีมุม θ1 (มุมข้อต่อฐาน) และ θ2 (มุมข้อต่อศอก
วัดสัมพัทธ์กับท่อนแขนแรก) ตำแหน่งของปลายแขน (x, y) คำนวณได้จากสมการตรีโกณมิติดังนี้

![ภาพที่ 2.1 แขนกลระนาบ 2 ท่อน (2-Link Planar Arm) และตัวแปรที่ใช้ในสมการจลนศาสตร์ตรง](/images/book/image12.png)

x = L1·cosθ1 + L2·cos(θ1 + θ2)

y = L1·sinθ1 + L2·sin(θ1 + θ2)

เมื่อทราบค่า θ1 และ θ2 สามารถแทนค่าลงในสมการทั้งสองเพื่อคำนวณตำแหน่ง (x, y)
ของปลายแขนได้โดยตรง สำหรับหุ่นยนต์ที่มีจำนวนแกนมากกว่า 2 แกน และเคลื่อนที่ในปริภูมิ 3 มิติ
จะใช้หลักการเดียวกันแต่ขยายเป็นสมการเมทริกซ์การแปลงพิกัดเอกพันธ์ ซึ่งจะกล่าวถึงในหัวข้อ
2.3

### 2.1.2 จลนศาสตร์ผกผัน (Inverse Kinematics)

จลนศาสตร์ผกผัน (Inverse Kinematics: IK) เป็นปัญหาตรงข้ามกับ FK
คือการคำนวณค่ามุมข้อต่อ (θ1, θ2, ...) ที่ต้องใช้ เพื่อให้ปลายแขนหุ่นยนต์ไปถึงตำแหน่ง (x,
y, z) และทิศทางที่ต้องการ ปัญหา IK มีความซับซ้อนกว่า FK มาก เนื่องจากโดยทั่วไปแล้ว
ที่ตำแหน่งปลายแขนเดียวกัน หุ่นยนต์อาจจัดท่าทางของข้อต่อได้มากกว่า 1 แบบ (Multiple
Solutions) หรือในบางกรณีอาจไม่มีคำตอบเลย (ตำแหน่งนั้นอยู่นอกขอบเขตการทำงาน)
หรือมีคำตอบไม่จำกัด (กรณีหุ่นยนต์มีความซ้ำซ้อนของแกน หรือ Redundant Manipulator)

สำหรับแขนกลระนาบ 2 ท่อน การแก้ปัญหา IK ด้วยวิธีเรขาคณิต (Geometric Approach)
จะได้คำตอบ 2 ชุดที่ให้ตำแหน่งปลายแขนเดียวกัน เรียกว่าท่าศอกงอขึ้น (Elbow-Up)
และท่าศอกงอลง (Elbow-Down) ขึ้นอยู่กับเครื่องหมายบวก/ลบที่เลือกในขั้นตอนการคำนวณมุม θ2
จากกฎโคไซน์ (Law of Cosines)
วิศวกรผู้เขียนโปรแกรมควบคุมต้องเลือกคำตอบที่เหมาะสมกับสภาพแวดล้อมการทำงานจริง เช่น
หลีกเลี่ยงการชนกับสิ่งกีดขวาง

![ภาพที่ 2.2 คำตอบสองแบบของจลนศาสตร์ผกผัน: ท่าศอกงอขึ้น (Elbow-Up) และศอกงอลง (Elbow-Down)](/images/book/image13.png)

ตารางที่ 2.1
เปรียบเทียบจลนศาสตร์ตรงและจลนศาสตร์ผกผัน

| หัวข้อเปรียบเทียบ       | จลนศาสตร์ตรง (Forward Kinematics) | จลนศาสตร์ผกผัน (Inverse Kinematics)     |
|---------------------|----------------------------------|---------------------------------------|
| ข้อมูลนำเข้า           | มุม/ระยะของข้อต่อ (θ1, θ2, ...)     | ตำแหน่งและทิศทางปลายแขน (x, y, z, ...)  |
| ผลลัพธ์               | ตำแหน่งและทิศทางปลายแขน            | มุม/ระยะของข้อต่อที่ต้องใช้                  |
| จำนวนคำตอบ          | มีคำตอบเดียวเสมอ (Unique)          | อาจมีหลายคำตอบ ไม่มีคำตอบ หรือไม่จำกัดคำตอบ |
| ความซับซ้อนในการคำนวณ | คำนวณตรงไปตรงมาด้วยสมการตรีโกณมิติ   | ซับซ้อนกว่า ต้องพิจารณาข้อจำกัดทางกลของหุ่นยนต์ |

### 2.1.3 การแปลงพิกัดเอกพันธ์ (Homogeneous Transformation)

สำหรับหุ่นยนต์ที่มีหลายข้อต่อและเคลื่อนที่ในปริภูมิ 3 มิติ
การคำนวณตำแหน่งปลายแขนด้วยตรีโกณมิติแบบง่ายไม่เพียงพอ วิศวกรจึงใช้
เมทริกซ์การแปลงพิกัดเอกพันธ์ (Homogeneous Transformation Matrix) ขนาด 4x4
ซึ่งรวมทั้งการหมุน (Rotation) และการเลื่อนตำแหน่ง (Translation) ไว้ในเมทริกซ์เดียว
แต่ละข้อต่อของหุ่นยนต์จะมีเมทริกซ์การแปลงพิกัดของตนเอง (เช่น T01 คือการแปลงพิกัดจากเฟรม
0 ไปเฟรม 1) และตำแหน่งของปลายแขนในระบบพิกัดโลกคำนวณได้จากผลคูณลูกโซ่ (Chain
Multiplication) ของเมทริกซ์การแปลงพิกัดทุกข้อต่อเรียงต่อกัน

T0n = T01 · T12 · T23 · ... · T(n-1)n

โดยที่ T0n คือเมทริกซ์การแปลงพิกัดรวมจากฐานหุ่นยนต์ (เฟรม 0) ไปยังปลายแขน (เฟรม n)
วิธีการกำหนดค่าพารามิเตอร์ของแต่ละข้อต่อ อย่างเป็นระบบที่นิยมใช้มากที่สุดคือแบบ
Denavit-Hartenberg (DH Parameters) ซึ่งกำหนดพารามิเตอร์ 4 ค่าต่อข้อต่อ ได้แก่
มุมข้อต่อ (θ) ระยะเยื้องแนวแกน (d) ความยาวแขน (a) และมุมบิดแกน (α)
การกำหนดพารามิเตอร์ตามมาตรฐานนี้ช่วยให้การเขียนโปรแกรมคำนวณ FK/IK
ของหุ่นยนต์หลายแกนเป็นระบบและตรวจสอบย้อนกลับได้ง่าย

![ภาพที่ 2.3 ลูกโซ่การแปลงพิกัดเอกพันธ์จากเฟรมฐาน (Frame 0) ถึงเฟรมปลายแขน (Frame n)](/images/book/image14.png)

### 2.1.4 ซอฟต์แวร์จำลองการเคลื่อนที่หุ่นยนต์

ก่อนนำโปรแกรมควบคุมไปใช้งานกับหุ่นยนต์จริง วิศวกรนิยมใช้ซอฟต์แวร์จำลอง (Simulation
Software) เช่น MATLAB Robotics Toolbox, RoboDK
หรือซอฟต์แวร์ของผู้ผลิตหุ่นยนต์แต่ละยี่ห้อ เพื่อนำแบบจำลอง CAD และค่าพารามิเตอร์ DH
ของหุ่นยนต์มาสร้างแบบจำลองเสมือน (Virtual Model) แล้วทดสอบคำนวณ FK/IK
ตรวจสอบขอบเขตการทำงาน (Work Envelope) และตรวจสอบการชนกัน (Collision
Detection) ระหว่างแขนกลกับอุปกรณ์รอบข้าง ก่อนอัปโหลดโปรแกรมเข้าหุ่นยนต์จริง
วิธีนี้ช่วยลดความเสี่ยงในการทดลองกับหุ่นยนต์จริง ประหยัดเวลา
และลดค่าใช้จ่ายจากความเสียหายที่อาจเกิดขึ้น อย่างไรก็ตาม
ซอฟต์แวร์จำลองไม่สามารถเปลี่ยนแปลงคุณสมบัติทางกลของหุ่นยนต์จริงได้ เช่น น้ำหนักบรรทุกสูงสุด
(Payload) หรือความเร็วสูงสุดของแกน ซึ่งถูกกำหนดโดยโครงสร้างและมอเตอร์ของหุ่นยนต์รุ่นนั้น
ๆ

## 2.2 การตรวจสอบจลนศาสตร์ตรงของแขนกล 2-DOF

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 2.1
เรื่องการตรวจสอบจลนศาสตร์ตรงของแขนกล 2-DOF ใช้เวลา 2 ชั่วโมง (120 นาที)
ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริง และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน
โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อมของอุปกรณ์ตามรายการ
และอ่านข้อควรระวังด้านความปลอดภัยร่วมกับครูผู้สอน (10 นาที)

ขั้นที่ 2 ประกอบแขนกล 2-DOF และต่อวงจรมอเตอร์เซอร์โว 2 ตัวเข้ากับบอร์ด ESP32
ตามผังวงจรในภาพที่ 2.5 (20 นาที)

ขั้นที่ 3 ให้ครูตรวจการต่อวงจร จากนั้นเชื่อมต่อบอร์ด ESP32 กับคอมพิวเตอร์
และเลือกพอร์ตสื่อสารในโปรแกรม VS Code (10 นาที)

ขั้นที่ 4 พิมพ์โค้ด main.py ตามตารางที่ 2.2 อัปโหลดไปยังบอร์ด และเปิดหน้าต่าง Serial
Monitor (20 นาที)

ขั้นที่ 5 สั่งมุมข้อต่อตามชุดมุมที่กำหนด วัดตำแหน่งปลายแขนจริงเปรียบเทียบกับค่าที่คำนวณได้
แล้วบันทึกลงแบบบันทึกผล (35 นาที)

ขั้นที่ 6 วิเคราะห์ผลการทดลองและตอบคำถามท้ายใบงาน (15 นาที)

ขั้นที่ 7 สรุปผล ส่งแบบบันทึกผล ถอดสายและเก็บอุปกรณ์ และทำความสะอาดพื้นที่ปฏิบัติงาน (10
นาที)

### 2.2.1 งานประกอบและต่อวงจรแขนกล 2-DOF

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถสังเกตการประกอบและต่อวงจรแขนกล 2-DOF
ด้วยมอเตอร์เซอร์โว 2 ตัวได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 2.1
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง การต่อวงจรมีขั้นตอนดังนี้

1\. ยึดเซอร์โว 1 (ข้อต่อฐาน θ1) กับฐานคงที่บนกระดาษกราฟ แล้วต่อท่อนแขน L1
เข้ากับแขนหมุนของเซอร์โว 1

2\. ยึดเซอร์โว 2 (ข้อต่อศอก θ2) ที่ปลายท่อนแขน L1 แล้วต่อท่อนแขน L2
เข้ากับแขนหมุนของเซอร์โว 2

3\. ต่อขาสัญญาณของเซอร์โว 1 เข้ากับ GPIO18 และขาสัญญาณของเซอร์โว 2 เข้ากับ GPIO19
ของ ESP32

4\. ต่อขา VCC ของเซอร์โวทั้งสองตัวเข้ากับ 5V และขา GND เข้ากับ GND ของ ESP32
หรือแหล่งจ่ายไฟภายนอก (ต่อ GND ร่วมกันเสมอ)

5\. ทำเครื่องหมายจุดฐาน (Origin) ของแขนกลบนกระดาษกราฟ
เพื่อใช้เป็นจุดอ้างอิงในการวัดตำแหน่งปลายแขน

ผู้เรียนสามารถดำเนินการวัดตำแหน่งปลายแขนและเปรียบเทียบกับค่าจากการคำนวณได้ถูกต้อง
โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 2.1
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง โดยคัดลอกโค้ดตามตารางที่ 2.2
ลงในไฟล์ main.py แล้วอัปโหลดไปยังบอร์ด ESP32 จากนั้นทดลองตามขั้นตอนต่อไปนี้

ตารางที่ 2.2 โค้ดภาษา
MicroPython สำหรับการตรวจสอบจลนศาสตร์ตรงของแขนกล 2-DOF

| \# main.py -- ESP32 MicroPython: 2-DOF planar arm forward kinematics demo               |
|-----------------------------------------------------------------------------------------|
| from machine import Pin, PWM                                                            |
| import time, math                                                                       |
|                                                                                         |
| servo1 = PWM(Pin(18), freq=50) \# theta1 - base joint                                   |
| servo2 = PWM(Pin(19), freq=50) \# theta2 - elbow joint                                  |
|                                                                                         |
| L1 = 15.0 \# cm                                                                         |
| L2 = 15.0 \# cm                                                                         |
|                                                                                         |
| def set_angle(servo, angle):                                                            |
| duty = int(1638 + (angle / 180) \* (8192 - 1638))                                       |
| servo.duty_u16(duty)                                                                    |
|                                                                                         |
| def forward_kinematics(theta1_deg, theta2_deg):                                         |
| t1 = math.radians(theta1_deg)                                                           |
| t2 = math.radians(theta2_deg)                                                           |
| x = L1 \* math.cos(t1) + L2 \* math.cos(t1 + t2)                                        |
| y = L1 \* math.sin(t1) + L2 \* math.sin(t1 + t2)                                        |
| return x, y                                                                             |
|                                                                                         |
| test_angles = \[(0, 90), (30, 60), (45, 45), (60, 30), (90, 0)\]                        |
| while True:                                                                             |
| for th1, th2 in test_angles:                                                            |
| set_angle(servo1, th1)                                                                  |
| set_angle(servo2, th2)                                                                  |
| x, y = forward_kinematics(th1, th2)                                                     |
| print('theta1=', th1, 'theta2=', th2, ' -\> predicted (x,y) =', round(x,2), round(y,2)) |
| time.sleep(2.0)                                                                         |

## 2.3 พลศาสตร์ของหุ่นยนต์

### 2.3.1 พลศาสตร์ของหุ่นยนต์และแรงบิด (Dynamics and Torque)

พลศาสตร์ (Dynamics) ของหุ่นยนต์ศึกษาความสัมพันธ์ระหว่างแรงหรือแรงบิดที่กระทำกับข้อต่อ
กับความเร่ง (Acceleration) ของการเคลื่อนที่ ต่างจากจลนศาสตร์ (Kinematics)
ซึ่งพิจารณาเฉพาะตำแหน่ง ความเร็ว และความเร่งโดยไม่คำนึงถึงแรงที่ทำให้เกิดการเคลื่อนที่นั้น
การวิเคราะห์พลศาสตร์มีความสำคัญอย่างยิ่งต่อการเลือกขนาดมอเตอร์ (Motor Sizing)
ให้เพียงพอต่อภาระงาน และต่อการออกแบบระบบควบคุม ให้สามารถชดเชยผลของแรงโน้มถ่วง
(Gravity) แรงเฉื่อย (Inertia) และแรงเสียดทาน (Friction) ได้อย่างเหมาะสม

แรงบิดที่ข้อต่อฐาน (τ1) ของแขนกล 2 ท่อนที่วางในแนวดิ่งและรับภาระที่ปลายแขน
จะต้องรับน้ำหนักของทุกส่วนที่อยู่ถัดจากข้อต่อนั้นออกไป ได้แก่ น้ำหนักของท่อนแขนที่ 1 ท่อนแขนที่ 2
และภาระ (Payload) ที่ปลายแขน ในขณะที่แรงบิดที่ข้อต่อศอก (τ2)
จะรับภาระเฉพาะน้ำหนักของท่อนแขนที่ 2 และภาระปลายแขนเท่านั้น
หลักการนี้แสดงให้เห็นว่าข้อต่อที่อยู่ใกล้ฐานมากที่สุดมักต้องการมอเตอร์ที่มีแรงบิดสูงที่สุดในระบบ

![ภาพที่ 2.6 แรงบิดที่ข้อต่อของแขนกล 2 ท่อน เนื่องจากน้ำหนักท่อนแขนและภาระปลายแขน](/images/book/image17.png)

### 2.3.2 การคำนวณแรงและโมเมนต์ที่กระทำต่อข้อต่อ (Free-Body Analysis)

การคำนวณแรงบิดที่ข้อต่อแต่ละข้ออย่างละเอียดทำได้ด้วยการเขียนแผนภาพวัตถุอิสระ (Free-Body
Diagram) ของแต่ละท่อนแขน แล้วพิจารณาสมดุลของแรง และโมเมนต์รอบข้อต่อ ณ ท่อนแขนใด ๆ
จะมีแรงปฏิกิริยาจากข้อต่อก่อนหน้า (Fi-1) แรงปฏิกิริยาที่ส่งต่อไปยังข้อต่อถัดไป (Fi)
น้ำหนักของท่อนแขนนั้นเอง และแรงบิดขับเคลื่อนของมอเตอร์ (τi)
โดยผลรวมของโมเมนต์รอบจุดหมุนต้องเท่ากับศูนย์ในกรณีสมดุลสถิต (Static Equilibrium)
หรือเท่ากับผลคูณของโมเมนต์ความเฉื่อย (Moment of Inertia)
กับความเร่งเชิงมุมในกรณีวิเคราะห์พลศาสตร์แบบเต็มรูปแบบ วิธีการนี้สามารถทำซ้ำไล่เรียง
จากปลายแขนกลับมายังฐาน (Backward Recursion)
เพื่อคำนวณแรงบิดที่ข้อต่อทุกข้อได้อย่างเป็นระบบ

![ภาพที่ 2.7 แผนภาพวัตถุอิสระ (Free-Body Diagram) ที่ข้อต่อ i ของแขนกลหุ่นยนต์](/images/book/image18.png)

### 2.3.3 การวิเคราะห์ความเร็วและความเร่งของหุ่นยนต์ (Jacobian)

ในการควบคุมหุ่นยนต์ให้เคลื่อนที่ด้วยความเร็วที่กำหนด (เช่น การเชื่อมต่อเนื่อง
หรือการติดตามเส้นทาง) จำเป็นต้องทราบความสัมพันธ์ระหว่าง ความเร็วเชิงมุมของข้อต่อ
(Joint Velocity, q̇) กับความเร็วเชิงเส้นและเชิงมุมของปลายแขน (End-Effector
Velocity, v) ความสัมพันธ์นี้อธิบายได้ ด้วยเมทริกซ์จาโคเบียน (Jacobian Matrix, J(q))
ผ่านสมการ v = J(q)·q̇ โดยเมทริกซ์จาโคเบียนเป็นฟังก์ชันของตำแหน่งข้อต่อปัจจุบัน (q)
ซึ่งหมายความว่าความสัมพันธ์ระหว่างความเร็วข้อต่อกับความเร็วปลายแขนจะเปลี่ยนแปลงไปตามท่าทางของหุ่นยนต์
ณ ขณะนั้น

ในบางท่าทางของหุ่นยนต์ เมทริกซ์จาโคเบียนจะสูญเสียอันดับเต็ม (Rank Deficiency)
เรียกว่าสภาวะเอกฐาน (Singularity) ซึ่งทำให้หุ่นยนต์
ไม่สามารถเคลื่อนที่ปลายแขนไปในบางทิศทางได้ แม้ข้อต่อจะหมุนด้วยความเร็วสูงเพียงใดก็ตาม
ตัวอย่างที่พบบ่อยคือเมื่อแขนกลเหยียดตรงสุด (Fully Extended)
วิศวกรผู้เขียนโปรแกรมควบคุมจำเป็นต้องออกแบบเส้นทางการเคลื่อนที่ให้หลีกเลี่ยงบริเวณใกล้สภาวะเอกฐาน
เพื่อป้องกันความเร็วข้อต่อที่สูงผิดปกติ ซึ่งอาจสร้างความเสียหายต่อมอเตอร์และกลไกได้

![ภาพที่ 2.8 ความสัมพันธ์ของเมทริกซ์จาโคเบียนระหว่างความเร็วข้อต่อและความเร็วปลายแขน](/images/book/image19.png)

## 2.4 การวิเคราะห์แรงบิดข้อต่อของแขนกล 2-DOF

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 2.2
เรื่องการวิเคราะห์แรงบิดข้อต่อของแขนกล 2-DOF ใช้เวลา 2 ชั่วโมง (120 นาที)
ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริง และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน
โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อมของอุปกรณ์ตามรายการ
และอ่านข้อควรระวังด้านความปลอดภัยร่วมกับครูผู้สอน (10 นาที)

ขั้นที่ 2 ชั่งมวลของตุ้มน้ำหนักและวัดความยาวท่อนแขน L1 และ L2 แล้วบันทึกค่า (15 นาที)

ขั้นที่ 3 คำนวณแรงบิดที่ข้อต่อฐานและข้อต่อศอกเมื่อแขนอยู่ในแนวนอนจากสมการ τ = m·g·d
สำหรับภาระแต่ละค่า (25 นาที)

ขั้นที่ 4 ให้ครูตรวจความพร้อม แล้วสั่งแขนกลไปที่ตำแหน่งแนวนอน (θ1 = 0 องศา และ θ2 = 0
องศา) ด้วยโปรแกรมจากใบงานปฏิบัติหน่วยเรียนที่ 2.1 (10 นาที)

ขั้นที่ 5 แขวนตุ้มน้ำหนักทีละค่าที่ปลายแขน สังเกตความสามารถในการคงตำแหน่งของข้อต่อ
แล้วบันทึกลงแบบบันทึกผล (35 นาที)

ขั้นที่ 6 เปรียบเทียบแรงบิดที่คำนวณได้กับแรงบิดพิกัดของมอเตอร์เซอร์โว
และตอบคำถามท้ายใบงาน (15 นาที)

ขั้นที่ 7 สรุปผล ส่งแบบบันทึกผล ถอดสายและเก็บอุปกรณ์ และทำความสะอาดพื้นที่ปฏิบัติงาน (10
นาที)

### 2.4.1 งานคำนวณแรงบิดข้อต่อตามภาระที่ปลายแขน

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว
ผู้เรียนสามารถสังเกตหลักการคำนวณแรงบิดข้อต่อตามภาระที่ปลายแขนได้ถูกต้อง
โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 2.2
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

แรงบิดที่ข้อต่อเนื่องจากภาระที่ปลายแขนเมื่อแขนอยู่ในแนวนอนหาได้จาก τ = m·g·d โดย m
คือมวลของภาระ g คือความเร่งเนื่องจากแรงโน้มถ่วงของโลก (9.81 m/s²) และ d
คือระยะจากแกนข้อต่อถึงจุดที่ภาระกระทำ สำหรับข้อต่อฐานใช้ d = L1 + L2 ส่วนข้อต่อศอกใช้ d
= L2 โดยไม่คิดน้ำหนักของท่อนแขน

ตัวอย่างเช่น ภาระ 50 กรัม ที่ปลายแขนซึ่งมี L1 = 15 ซม. และ L2 = 10 ซม.
จะเกิดแรงบิดที่ข้อต่อฐานเท่ากับ 0.05 × 9.81 × 0.25 ≈ 0.12 N·m และที่ข้อต่อศอกเท่ากับ
0.05 × 9.81 × 0.10 ≈ 0.05 N·m

### 2.4.2 งานทดสอบการรับภาระของข้อต่อด้วยมอเตอร์เซอร์โว

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว
ผู้เรียนสามารถดำเนินการทดสอบการรับภาระของข้อต่อด้วยมอเตอร์เซอร์โวและบันทึกผลได้ถูกต้อง
โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 2.2
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

นำค่าที่คำนวณได้เปรียบเทียบกับแรงบิดพิกัดของมอเตอร์เซอร์โว SG90 (ประมาณ 1.8 kg·cm
หรือ 0.18 N·m ที่แรงดัน 4.8 V) หากแรงบิดที่ต้องการเกินพิกัด
แขนกลจะไม่สามารถคงตำแหน่งได้
ผลการทดลองจึงช่วยให้ผู้เรียนเห็นความสำคัญของการคำนวณพลศาสตร์ในการเลือกขนาดมอเตอร์ของหุ่นยนต์จริง

**1. แขนกลระนาบ 2 ท่อน มี L1 = 30 ซม. L2 = 20 ซม. หาก θ1 = 0 องศา และ θ2 = 90 องศา จงคำนวณตำแหน่ง (x, y) ของปลายแขน**

<details><summary>เฉลย</summary>

90 องศา จงคำนวณตำแหน่ง (x, y) ของปลายแขน

จากสมการ x = L1cosθ1 + L2cos(θ1+θ2) = 30cos(0) + 20cos(90) = 30 + 0 = 30
ซม. และ y = L1sinθ1 + L2sin(θ1+θ2) = 30sin(0) + 20sin(90) = 0 + 20 = 20
ซม. ดังนั้นปลายแขนอยู่ที่ตำแหน่ง (30, 20) ซม.

</details>

**2. เพราะเหตุใดปัญหาจลนศาสตร์ผกผัน (Inverse Kinematics) จึงอาจมีคำตอบมากกว่า 1 คำตอบ ในขณะที่จลนศาสตร์ตรงมีคำตอบเดียวเสมอ**

<details><summary>เฉลย</summary>

คำตอบ ในขณะที่จลนศาสตร์ตรงมีคำตอบเดียวเสมอ

เพราะที่ตำแหน่งปลายแขนตำแหน่งเดียวกัน หุ่นยนต์สามารถจัดท่าทางของข้อต่อได้มากกว่า 1 แบบ
เช่น ท่าศอกงอขึ้น (Elbow-Up) หรือศอกงอลง (Elbow-Down)
ในขณะที่จลนศาสตร์ตรงเมื่อกำหนดมุมข้อต่อแน่นอนแล้ว
ตำแหน่งปลายแขนย่อมถูกกำหนดตามไปด้วยเพียงค่าเดียว

</details>

**3. จงอธิบายความหมายของเมทริกซ์การแปลงพิกัดเอกพันธ์ (Homogeneous Transformation Matrix) และเหตุใดจึงต้องคูณต่อกันเป็นลูกโซ่**

<details><summary>เฉลย</summary>

Matrix) และเหตุใดจึงต้องคูณต่อกันเป็นลูกโซ่

เป็นเมทริกซ์ขนาด 4x4 ที่รวมทั้งการหมุนและการเลื่อนตำแหน่งของแต่ละข้อต่อไว้ในเมทริกซ์เดียว
ต้องคูณต่อกันเป็นลูกโซ่ (T0n = T01·T12·...·T(n-1)n)
เพราะตำแหน่งของปลายแขนในระบบพิกัดโลกเป็นผลสะสมของการแปลงพิกัดของข้อต่อทุกข้อตั้งแต่ฐานจนถึงปลายแขน

</details>

**4. จงยกตัวอย่างประโยชน์ของการใช้ซอฟต์แวร์จำลอง (เช่น RoboDK หรือ MATLAB Robotics Toolbox) ก่อนใช้งานหุ่นยนต์จริง 3 ข้อ**

<details><summary>เฉลย</summary>

Robotics Toolbox) ก่อนใช้งานหุ่นยนต์จริง 3 ข้อ

ตัวอย่างเช่น (1) ตรวจสอบขอบเขตการทำงาน (Work Envelope)
ว่าครอบคลุมพื้นที่งานจริงหรือไม่ (2) ตรวจสอบการชนกัน (Collision)
ระหว่างแขนกลกับอุปกรณ์รอบข้าง (3) ทดสอบโปรแกรมควบคุมก่อนอัปโหลดเข้าหุ่นยนต์จริง
ช่วยลดความเสี่ยงและความเสียหาย

</details>

**5. เพราะเหตุใดข้อต่อที่อยู่ใกล้ฐานหุ่นยนต์มากที่สุดจึงมักต้องการมอเตอร์ที่มีแรงบิดสูงที่สุดในระบบ**

<details><summary>เฉลย</summary>

เพราะแรงบิดที่ข้อต่อใดข้อต่อหนึ่งต้องรับภาระน้ำหนักของทุกส่วน (ท่อนแขนและภาระ)
ที่อยู่ถัดจากข้อต่อนั้นออกไปจนถึงปลายแขน
ข้อต่อที่ใกล้ฐานที่สุดจึงต้องรับน้ำหนักสะสมของท่อนแขนและภาระทั้งหมด ทำให้ต้องการแรงบิดสูงที่สุด

</details>

**6. จงอธิบายหลักการของการวิเคราะห์แบบแผนภาพวัตถุอิสระ (Free-Body Diagram) แบบไล่เรียงย้อนกลับ (Backward Recursion) ในการคำนวณแรงบิดข้อต่อ**

<details><summary>เฉลย</summary>

แบบไล่เรียงย้อนกลับ (Backward Recursion) ในการคำนวณแรงบิดข้อต่อ

เป็นการเขียนแผนภาพวัตถุอิสระของแต่ละท่อนแขน โดยเริ่มคำนวณจากท่อนแขนปลายสุด (ใกล้
End-Effector) แล้วไล่เรียงย้อนกลับมาทีละท่อนจนถึงฐาน
โดยแรงปฏิกิริยาจากข้อต่อถัดไปที่คำนวณได้จะถูกนำมาใช้เป็นข้อมูลนำเข้าของการคำนวณข้อต่อก่อนหน้า
ทำให้คำนวณแรงบิดที่ข้อต่อทุกข้อได้อย่างเป็นระบบ

</details>

**7. เมทริกซ์จาโคเบียน (Jacobian) มีความสำคัญอย่างไรต่อการควบคุมความเร็วของหุ่นยนต์ และสภาวะเอกฐาน (Singularity) ส่งผลเสียอย่างไร**

<details><summary>เฉลย</summary>

และสภาวะเอกฐาน (Singularity) ส่งผลเสียอย่างไร

เมทริกซ์จาโคเบียนใช้เชื่อมโยงความเร็วข้อต่อ (q̇) กับความเร็วปลายแขน (v) ผ่านสมการ v =
J(q)·q̇ ทำให้ควบคุมความเร็วการเคลื่อนที่ของปลายแขนได้อย่างแม่นยำ เมื่อเกิดสภาวะเอกฐาน
เมทริกซ์จาโคเบียนจะสูญเสียอันดับเต็ม ทำให้หุ่นยนต์ไม่สามารถเคลื่อนที่ปลายแขนในบางทิศทางได้
และอาจต้องใช้ความเร็วข้อต่อสูงผิดปกติจนเป็นอันตรายต่อมอเตอร์และกลไก

</details>

**8. แขนกลระนาบ 2 ท่อน L1 = 25 ซม. L2 = 25 ซม. ต้องการให้ปลายแขนไปถึงตำแหน่ง (x, y) = (25, 25) ซม. หากใช้ θ1 = 0 องศา จงตรวจสอบว่า θ2 = 90 องศา ให้คำตอบที่ถูกต้องหรือไม่ โดยแทนค่าตรวจสอบ**

<details><summary>เฉลย</summary>

(x, y) = (25, 25) ซม. หากใช้ θ1 = 0 องศา จงตรวจสอบว่า θ2 = 90 องศา
ให้คำตอบที่ถูกต้องหรือไม่ โดยแทนค่าตรวจสอบ

แทนค่า x = 25cos(0) + 25cos(0+90) = 25 + 0 = 25 ซม. และ y = 25sin(0) +
25sin(0+90) = 0 + 25 = 25 ซม. ได้ตำแหน่ง (25, 25) ตรงกับที่ต้องการ ดังนั้น θ1 = 0
องศา และ θ2 = 90 องศา เป็นคำตอบที่ถูกต้องของปัญหาจลนศาสตร์ผกผันนี้

</details>

**9. จงอธิบายความแตกต่างระหว่างจลนศาสตร์ตรงและจลนศาสตร์ผกผัน พร้อมยกตัวอย่างการนำไปใช้งาน**

<details><summary>เฉลย</summary>

พร้อมยกตัวอย่างการนำไปใช้งาน

จลนศาสตร์ตรงคำนวณตำแหน่งและทิศทางของปลายแขนจากมุมหรือระยะของข้อต่อที่ทราบค่า
ซึ่งมีคำตอบเดียวเสมอ ใช้ตรวจสอบตำแหน่งปลายแขนขณะหุ่นยนต์ทำงาน
ส่วนจลนศาสตร์ผกผันคำนวณมุมข้อต่อที่ต้องใช้เพื่อให้ปลายแขนไปถึงตำแหน่งที่ต้องการ
อาจมีหลายคำตอบหรือไม่มีคำตอบ ใช้ในการสั่งให้หุ่นยนต์เคลื่อนที่ไปยังตำแหน่งหยิบหรือวางชิ้นงาน

</details>

**10. แขนกลระนาบ 2 ท่อน มี L1 = 0.3 m และ L2 = 0.2 m หาก θ1 = 30 องศา และ θ2 = 60 องศา จงคำนวณตำแหน่งปลายแขน (x, y)**

<details><summary>เฉลย</summary>

θ2 = 60 องศา จงคำนวณตำแหน่งปลายแขน (x, y)

x = 0.3cos(30°) + 0.2cos(90°) = 0.260 + 0 = 0.260 m และ y =
0.3sin(30°) + 0.2sin(90°) = 0.150 + 0.200 = 0.350 m ดังนั้นตำแหน่งปลายแขนคือ
(0.260, 0.350) m

</details>
