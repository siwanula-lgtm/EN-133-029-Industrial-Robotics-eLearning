    - 3.2.2 อธิบายหลักการทำงานของเซนเซอร์สำหรับหุ่นยนต์อุตสาหกรรมแต่ละประเภทได้

    - 3.3.2 อธิบายการใช้โปรแกรมย่อยและฟังก์ชันนับจำนวนรอบการทำงานได้

## 3.1 ระบบควบคุมและวิธีการโปรแกรมหุ่นยนต์

### 3.1.1 ประเภทของระบบควบคุมหุ่นยนต์

ระบบควบคุมของหุ่นยนต์อุตสาหกรรมแบ่งออกได้เป็น 4 ประเภทหลัก
ตามความสามารถและความซับซ้อนของการทำงาน ได้แก่ การควบคุมแบบลำดับขั้นอย่างง่าย
(Limited Sequence Control)
ซึ่งใช้จุดหยุดทางกลหรือสัญญาณเซนเซอร์กำหนดลำดับการเคลื่อนที่ของแต่ละข้อต่อ
เหมาะกับงานที่มีรอบการทำงานไม่ซับซ้อน เช่น การหยิบ-วางชิ้นงาน
การควบคุมแบบเล่นซ้ำจุดต่อจุด (Playback Point-to-Point: PTP)
ซึ่งตัวควบคุมจดจำตำแหน่งจากการสอนงานแล้วเล่นซ้ำตามลำดับ
การควบคุมแบบเล่นซ้ำเส้นทางต่อเนื่อง (Playback Continuous Path: CP)
ที่บันทึกเส้นทางอย่างละเอียดเหมาะกับงานเชื่อมหรือพ่นสี และการควบคุมอัจฉริยะ (Intelligent
Control)
ที่หุ่นยนต์สามารถตอบสนองต่อสภาพแวดล้อมและตัดสินใจได้เองเมื่อพบสิ่งผิดปกติระหว่างการทำงาน

![ภาพที่ 3.1 ประเภทของระบบควบคุมหุ่นยนต์ 4 แบบ (Robot Control System Types)](/images/book/image20.png)

### 3.1.2 วิธีการโปรแกรมหุ่นยนต์

การโปรแกรมหุ่นยนต์อุตสาหกรรมมี 3 วิธีหลัก ได้แก่ การสอนงานผ่านแผงสอนงาน
(Leadthrough Programming) โดยควบคุมแขนหุ่นยนต์ไปยังตำแหน่งจริง ด้วย Teach
Pendant แล้วบันทึกตำแหน่งแบบจุดต่อจุด เหมาะกับงานที่ไม่ซับซ้อน
การเขียนโปรแกรมด้วยภาษาคล้ายคอมพิวเตอร์ (Computer-like Robot Programming
Language) เช่น ภาษา MELFA BASIC ของ Mitsubishi หรือ KRL ของ KUKA
ซึ่งสามารถเพิ่มการใช้งานเซนเซอร์ สัญญาณอนาล็อก/ดิจิทัล และตรรกะเงื่อนไขที่ซับซ้อนได้
และการโปรแกรมแบบออฟไลน์ (Off-line Programming)
ซึ่งเตรียมและทดสอบโปรแกรมบนคอมพิวเตอร์ก่อนดาวน์โหลดเข้าหุ่นยนต์จริง
โดยไม่ขัดจังหวะสายการผลิต
วิธีนี้ได้รับความนิยมเพิ่มขึ้นเนื่องจากลดเวลาหยุดสายการผลิตในการเปลี่ยนงาน

![ภาพที่ 3.2 วิธีการโปรแกรมหุ่นยนต์ 3 วิธี (Robot Programming Methods)](/images/book/image21.png)

### 3.1.3 อุปกรณ์สอนโปรแกรม (Teach Pendant) และระดับผู้ใช้งาน

แผงสอนงาน (Teach Pendant) เป็นอุปกรณ์ควบคุมและโปรแกรมหุ่นยนต์ที่ผู้ปฏิบัติงานใช้บ่อยที่สุด
ประกอบด้วยจอแสดงผลแบบสัมผัส (Touch Panel) สำหรับแสดงและแก้ไขโปรแกรม
สวิตช์ควบคุมการทำงาน (Operation Switch) เช่น Start/Stop และสวิตช์ฉุกเฉิน
(Emergency Switch) และปุ่มกด (Optimal Key)
สำหรับควบคุมการเคลื่อนที่ของแขนหุ่นยนต์ทีละแกนขณะทำการสอนงาน (Teaching)
โดยทั่วไปมีการกำหนดระดับผู้ใช้งานไว้ 3 ระดับ คือ Operator ซึ่งใช้งานพื้นฐานอย่าง
Start/Stop โดยไม่ต้องใช้รหัสผ่าน Engineer
ซึ่งสามารถแก้ไขและปรับตำแหน่งโปรแกรมได้โดยต้องใช้รหัสผ่าน และ Administrator
ซึ่งมีสิทธิ์สูงสุดในการตั้งค่าระบบและกำหนดสิทธิ์ผู้ใช้งานระดับอื่น

![ภาพที่ 3.3 อุปกรณ์สอนโปรแกรม (Teach Pendant) และระดับผู้ใช้งาน](/images/book/image22.png)

## 3.2 คำสั่งพื้นฐานและเซนเซอร์สำหรับหุ่นยนต์

### 3.2.1 คำสั่งพื้นฐานในการควบคุมการเคลื่อนที่และอุปกรณ์ปลายแขน

ภาษาโปรแกรมหุ่นยนต์อุตสาหกรรม เช่น MELFA BASIC IV มีคำสั่งพื้นฐานที่ใช้บ่อยดังนี้ MOV
(Position) สั่งให้หุ่นยนต์เคลื่อนที่ไปยังตำแหน่งที่กำหนด
โดยคำนวณระยะทางและทิศทางที่เหมาะสมที่สุด เคลื่อนที่แบบ Joint Interpolation ส่วน MVS
(Position) สั่งให้เคลื่อนที่ไปยังตำแหน่งตามแนวเส้นตรง (Linear Interpolation) คำสั่ง
OVRD (0-100%) กำหนดความเร็วโดยรวม (Override Speed) ของการเคลื่อนที่
ในขณะที่คำสั่ง SPD ใช้กำหนดความเร็วผ่านตัวแปร ที่ตั้งชื่อไว้ล่วงหน้าด้วยคำสั่ง DEF INTE เช่น
FAST หรือ SLOW คำสั่ง DLY (Time Sec) ใช้หน่วงเวลาก่อนทำงานขั้นตอนถัดไป และคำสั่ง
HOPEN/HCLOSE (Hand Tools Number) ใช้เปิด/ปิดมือจับ (Gripper)
เพื่อปล่อยหรือยึดจับชิ้นงาน

ตารางที่ 3.1
คำสั่งพื้นฐานควบคุมการเคลื่อนที่และมือจับของหุ่นยนต์

| คำสั่ง           | ความหมาย                                  | ตัวอย่าง   |
|----------------|-------------------------------------------|----------|
| MOV P1         | เคลื่อนที่ไปตำแหน่ง P1 แบบ Joint Interpolation | MOV P1   |
| MVS P2         | เคลื่อนที่ไปตำแหน่ง P2 แบบเส้นตรง (Linear)      | MVS P2   |
| OVRD n         | กำหนดความเร็วโดยรวม n เปอร์เซ็นต์             | OVRD 70  |
| DLY t          | หน่วงเวลา t วินาที                           | DLY 0.5  |
| HCLOSE / HOPEN | ปิด / เปิดมือจับ (Gripper)                    | HCLOSE 1 |

### 3.2.2 ประเภทของเซนเซอร์สำหรับหุ่นยนต์อุตสาหกรรม

เซนเซอร์ที่ใช้ในระบบหุ่นยนต์อุตสาหกรรมแบ่งได้เป็น 2 ประเภทหลัก คือ เซนเซอร์ภายใน
(Internal Sensor) ซึ่งใช้ควบคุมตำแหน่งและความเร็วของแต่ละข้อต่อ ภายในตัวหุ่นยนต์เอง
เช่น เอนโค้ดเดอร์ (Encoder) และเซนเซอร์ภายนอก (External Sensor)
ซึ่งใช้ประสานงานหุ่นยนต์ให้เข้ากับอุปกรณ์อื่นภายในเซลล์การผลิต (Work Cell)
เซนเซอร์ภายนอกที่พบบ่อยได้แก่ เซนเซอร์สัมผัส (Tactile Sensor)
ที่ตรวจจับการสัมผัสระหว่างมือจับกับวัตถุ เซนเซอร์ตรวจจับวัตถุใกล้เคียง (Proximity Sensor)
เซนเซอร์ตรวจจับแสงหรือวัตถุแบบโฟโต้เซลล์ (Optical Sensor/Photocell)
และกล้องตรวจสอบภาพ (Machine Vision) ที่ใช้ตรวจสอบ ความบกพร่องของชิ้นงาน
บ่งชี้ตำแหน่งชิ้นงาน หรือช่วยนำทางการเคลื่อนที่ นอกจากนี้ยังมีเซนเซอร์อื่น ๆ ที่วัดค่าทางกายภาพ
เช่น อุณหภูมิ ความดันของไหล อัตราการไหล และแรงดัน/กระแสไฟฟ้า

![ภาพที่ 3.4 การจำแนกเซนเซอร์สำหรับหุ่นยนต์อุตสาหกรรม (Sensors in Robotics)](/images/book/image23.png)

## 3.3 การเขียนโปรแกรมแบบมีเงื่อนไขและโปรแกรมย่อย

### 3.3.1 การเขียนโปรแกรมแบบมีเงื่อนไขร่วมกับสัญญาณเซนเซอร์

การนำสัญญาณจากเซนเซอร์มาใช้ในโปรแกรมควบคุมหุ่นยนต์ทำได้ผ่านคำสั่งกำหนด Input/Output
โดยคำสั่ง M_IN(Bit Number) ใช้อ่านสถานะสัญญาณเข้า จากเซนเซอร์ (0 = OFF, 1 = ON)
และคำสั่ง M_OUT(Bit Number) ใช้กำหนดสถานะสัญญาณออกไปควบคุมอุปกรณ์ภายนอก เช่น
วาล์วลม หรือมือจับ เมื่อรวมกับคำสั่งเงื่อนไข IF...THEN...ELSE...GOTO
จะสามารถเขียนโปรแกรมให้หุ่นยนต์ตัดสินใจได้ตามสถานะของเซนเซอร์ เช่น หากตรวจพบชิ้นงาน
(M_IN(1) = 1) ให้กระโดดไปทำงานส่วนหยิบชิ้นงาน มิฉะนั้นให้วนรอกลับไปตรวจสอบใหม่
นอกจากนี้ยังนิยมใช้คำสั่ง DEF IO เพื่อตั้งชื่อบิต I/O ให้สื่อความหมาย เช่น DEF IO SENSOR1
= BIT,1 แทนการอ้างอิงหมายเลขบิตโดยตรง ทำให้โปรแกรมอ่านและตรวจสอบแก้ไขได้ง่ายขึ้น

![ภาพที่ 3.5 ผังงานโปรแกรมควบคุมแบบลำดับขั้นร่วมกับเซนเซอร์ (Pick-and-Place)](/images/book/image24.png)

![ภาพที่ 3.6 วงจรควบคุม Sensor-Controller-Actuator ผ่านคำสั่ง I/O](/images/book/image25.png)

### 3.3.2 โปรแกรมย่อยและฟังก์ชันนับจำนวนรอบการทำงาน

เมื่อโปรแกรมควบคุมหุ่นยนต์มีความซับซ้อนมากขึ้น หรือมีชุดคำสั่งที่ต้องเรียกใช้ซ้ำหลายครั้ง (เช่น
ขั้นตอนการหยิบชิ้นงาน) นิยมแยกชุดคำสั่งนั้นออกเป็น โปรแกรมย่อย (Subroutine)
แล้วเรียกใช้ด้วยคำสั่ง GOSUB \*ชื่อโปรแกรมย่อย เมื่อโปรแกรมย่อยทำงานถึงคำสั่ง RETURN
จะกลับมาทำงานต่อจากบรรทัดถัดจาก GOSUB ทันที
วิธีนี้ช่วยให้โปรแกรมหลักอ่านง่ายและแก้ไขได้สะดวก
อีกฟังก์ชันที่ใช้บ่อยในการควบคุมแบบลำดับขั้นคือการนับจำนวนรอบการทำงานด้วยตัวแปร COUNTER
ซึ่งเพิ่มค่าขึ้นทีละ 1 ในแต่ละรอบ (COUNTER = COUNTER + 1) แล้วใช้คำสั่ง IF COUNTER =
n THEN GOTO ตรวจสอบว่าครบจำนวนรอบที่ต้องการหรือไม่
เพื่อควบคุมจำนวนชิ้นงานที่ผลิตหรือหยุดการทำงานเมื่อครบเงื่อนไขที่กำหนด

## 3.4 การเขียนโปรแกรมควบคุมแบบลำดับขั้นร่วมกับเซนเซอร์

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 3
เรื่องการเขียนโปรแกรมควบคุมแบบลำดับขั้นร่วมกับเซนเซอร์ ใช้เวลา 2 ชั่วโมง (120 นาที)
ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริง และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน
โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อมของอุปกรณ์ตามรายการ
และอ่านข้อควรระวังด้านความปลอดภัยร่วมกับครูผู้สอน (10 นาที)

ขั้นที่ 2 ต่อวงจรเซนเซอร์ตรวจจับชิ้นงานและอุปกรณ์เอาต์พุตเข้ากับบอร์ด ESP32
ตามผังวงจรในภาพที่ 3.7 (20 นาที)

ขั้นที่ 3 ให้ครูตรวจการต่อวงจร จากนั้นเชื่อมต่อบอร์ด ESP32 กับคอมพิวเตอร์
และเลือกพอร์ตสื่อสารในโปรแกรม VS Code (10 นาที)

ขั้นที่ 4 พิมพ์โค้ด main.py ตามตารางที่ 3.2 อัปโหลดไปยังบอร์ด และเปิดหน้าต่าง Serial
Monitor (20 นาที)

ขั้นที่ 5 ทดสอบการทำงานแบบลำดับขั้นทั้งกรณีมีชิ้นงานและไม่มีชิ้นงาน แล้วบันทึกลงแบบบันทึกผล
(35 นาที)

ขั้นที่ 6 วิเคราะห์ผลการทดลองและตอบคำถามท้ายใบงาน (15 นาที)

ขั้นที่ 7 สรุปผล ส่งแบบบันทึกผล ถอดสายและเก็บอุปกรณ์ และทำความสะอาดพื้นที่ปฏิบัติงาน (10
นาที)

### 3.4.1 งานต่อวงจรเซนเซอร์ตรวจจับชิ้นงานกับบอร์ด ESP32

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถสังเกตการต่อวงจรเซนเซอร์ตรวจจับชิ้นงานกับบอร์ด
ESP32 ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 3
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง การต่อวงจรมีขั้นตอนดังนี้

1\. ต่อขา VCC และ GND ของโมดูลเซนเซอร์ IR เข้ากับ 3.3V/5V และ GND ของ ESP32
ตามสเปกของโมดูล

2\. ต่อขาสัญญาณ OUT ของโมดูลเซนเซอร์ IR เข้ากับขา GPIO4 ของ ESP32

3\. ต่อขาสัญญาณ (Signal) ของมอเตอร์เซอร์โวเข้ากับขา GPIO18 ของ ESP32

4\. ต่อขา VCC และ GND ของมอเตอร์เซอร์โวเข้ากับ 5V และ GND ของ ESP32
หรือแหล่งจ่ายไฟภายนอก (ต่อ GND ร่วมกันเสมอ)

5\. ปรับความไวของโมดูลเซนเซอร์ IR (หากมีสกรูปรับ) ให้ตรวจจับวัตถุที่ระยะประมาณ 5-10
เซนติเมตร

### 3.4.2 งานเขียนโปรแกรมลำดับขั้นตามสัญญาณเซนเซอร์

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว
ผู้เรียนสามารถดำเนินการเขียนโปรแกรมควบคุมลำดับขั้นตามสัญญาณเซนเซอร์และบันทึกผลได้ถูกต้อง
โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 3
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง โดยคัดลอกโค้ดตามตารางที่ 3.2
ลงในไฟล์ main.py แล้วอัปโหลดไปยังบอร์ด ESP32 จากนั้นทดลองตามขั้นตอนต่อไปนี้

ตารางที่ 3.2 โค้ดภาษา
MicroPython สำหรับการเขียนโปรแกรมควบคุมแบบลำดับขั้นร่วมกับเซนเซอร์

| \# main.py -- ESP32 MicroPython: sequential control with sensor check                  |
|----------------------------------------------------------------------------------------|
| \# Simulates robot commands: M_IN (sensor read) / HCLOSE-HOPEN (gripper) / GOTO (loop) |
| from machine import Pin, PWM                                                           |
| import time                                                                            |
|                                                                                        |
| sensor = Pin(4, Pin.IN) \# เทียบเท่า M_IN(1)                                             |
| gripper = PWM(Pin(18), freq=50) \# เทียบเท่า HCLOSE / HOPEN                              |
|                                                                                        |
| def set_gripper(angle):                                                                |
| duty = int(1638 + (angle / 180) \* (8192 - 1638))                                      |
| gripper.duty_u16(duty)                                                                 |
|                                                                                        |
| def hopen():                                                                           |
| set_gripper(90) \# gripper open                                                        |
| print('HOPEN 1 -- มือจับเปิด')                                                            |
|                                                                                        |
| def hclose():                                                                          |
| set_gripper(0) \# gripper close                                                        |
| print('HCLOSE 1 -- มือจับปิด (ยึดชิ้นงาน)')                                                  |
|                                                                                        |
| counter = 0                                                                            |
| hopen()                                                                                |
| while True:                                                                            |
| m_in1 = sensor.value() \# M_IN(1) : 0 หรือ 1 ตามชนิดโมดูล                                 |
| print('M_IN(1) =', m_in1)                                                              |
| if m_in1 == 1: \# IF M_IN(1) = 1 THEN \*PICK ELSE \*WAIT                               |
| hclose()                                                                               |
| time.sleep(1.0) \# DLY 1.0                                                             |
| hopen()                                                                                |
| counter += 1 \# COUNTER = COUNTER + 1                                                  |
| print('COUNTER =', counter)                                                            |
| time.sleep(0.5)                                                                        |

1\. เปิดโปรแกรม Visual Studio Code เชื่อมต่อ ESP32 ผ่าน USB แล้วอัปโหลดไฟล์
main.py ตามตารางที่ 3.2

2\. เปิดหน้าต่าง Serial Monitor เพื่อดูค่า M_IN(1) และค่า COUNTER ที่เปลี่ยนแปลง

3\. นำชิ้นงานทดสอบเข้าใกล้เซนเซอร์ IR ในระยะที่กำหนด แล้วสังเกตว่ามือจับ (เซอร์โว)
ปิด-เปิดตามที่โปรแกรมไว้หรือไม่

4\. ทดลองนำชิ้นงานเข้า-ออกบริเวณตรวจจับ 5 ครั้ง แล้วบันทึกผลค่า M_IN(1)
และสถานะมือจับที่สังเกตได้ลงในแบบบันทึกผลการปฏิบัติงาน

ให้วิเคราะห์ว่าผลจากตารางที่บันทึกได้สอดคล้องกับหลักการ IF...THEN ที่ตรวจสอบค่า M_IN
หรือไม่ และอธิบายว่าหากค่าที่อ่านได้ไม่ตรงกับที่คาดหวัง อาจเกิดจากสาเหตุใดได้บ้าง (เช่น
ระยะตรวจจับ ความไวของเซนเซอร์ หรือสัญญาณรบกวน)

## บทสรุป

ระบบควบคุมหุ่นยนต์แบ่งได้หลายประเภทตามลักษณะการควบคุมเส้นทาง
การโปรแกรมหุ่นยนต์ทำได้ทั้งแบบใช้แผงสอนงานและแบบออฟไลน์
โดยมีคำสั่งพื้นฐานสำหรับการเคลื่อนที่และการควบคุมอุปกรณ์ปลายแขน
เซนเซอร์ช่วยให้หุ่นยนต์รับรู้สภาพแวดล้อมและชิ้นงาน
การเขียนโปรแกรมแบบมีเงื่อนไขร่วมกับสัญญาณเซนเซอร์ โปรแกรมย่อย และตัวนับจำนวนรอบ
ทำให้หุ่นยนต์ทำงานแบบลำดับขั้นได้อย่างถูกต้องและยืดหยุ่น
