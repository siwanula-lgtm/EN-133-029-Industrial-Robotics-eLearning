## 4.1 การควบคุมแบบต่อเนื่องและการโปรแกรมตำแหน่ง

### 4.1.1 หลักการควบคุมแบบต่อเนื่อง (Continuous Path Control)

การควบคุมแบบต่อเนื่อง (Continuous Path Control: CP)
เป็นการเคลื่อนที่ของหุ่นยนต์ผ่านตำแหน่งหลายจุดอย่างต่อเนื่องเป็นเส้นโค้งเรียบ
โดยไม่มีจุดหยุดกะทันหันระหว่างทาง แตกต่างจากการควบคุมแบบจุดต่อจุด (Point-to-Point:
PTP) ที่หุ่นยนต์เคลื่อนที่เป็นเส้นตรงจากจุดหนึ่งไปยังอีกจุดหนึ่ง และหยุดสั้น ๆ
ที่แต่ละจุดก่อนเคลื่อนที่ต่อ การเลือกใช้ระหว่าง PTP และ CP ขึ้นอยู่กับลักษณะงาน โดย PTP
เหมาะกับงานที่เน้นความแม่นยำของตำแหน่งปลายทาง เช่น การหยิบ-วางชิ้นงาน ส่วน CP
เหมาะกับงานที่ต้องการเส้นทางเรียบต่อเนื่อง เช่น การเชื่อมตะเข็บโค้งยาว การพ่นสี
หรือการตัดชิ้นงานตามแนวโค้ง ซึ่งการเคลื่อนที่แบบ CP ต้องอาศัยการคำนวณ Blending
เพื่อให้ความเร็วและทิศทางเปลี่ยนแปลงอย่างราบรื่นระหว่างช่วงเส้นทาง

![ภาพที่ 4.1 เปรียบเทียบเส้นทางการเคลื่อนที่ Point-to-Point (PTP) กับ Continuous Path (CP)](/images/book/image27.png)

### 4.1.2 การเขียนโปรแกรมเคลื่อนที่ต่อเนื่องหลายจุดด้วยคำสั่ง MVS

วิธีพื้นฐานที่สุดในการสร้างเส้นทางต่อเนื่องคือการเขียนคำสั่งเคลื่อนที่แบบเส้นตรง (MVS)
เรียงต่อกันหลายบรรทัดโดยไม่แทรกคำสั่งหยุดหรือหน่วงเวลา (DLY) ระหว่างกลาง
เมื่อโปรแกรมทำงานถึงคำสั่ง MVS ตำแหน่งถัดไปก่อนที่จะเคลื่อนที่ถึงตำแหน่งก่อนหน้าสมบูรณ์
ตัวควบคุมจะคำนวณเส้นทางที่ผสานกัน (Blend)
ให้หุ่นยนต์เคลื่อนที่ผ่านตำแหน่งกลางทางอย่างต่อเนื่องโดยไม่หยุดสนิท
ยิ่งกำหนดจุดตำแหน่งถี่มากเท่าใด เส้นทางที่ได้ก็จะยิ่งใกล้เคียงกับเส้นโค้ง ที่ต้องการมากขึ้นเท่านั้น
วิธีนี้เหมาะกับการสร้างเส้นทางตามแนวโค้งอย่างง่ายโดยไม่ต้องใช้คำสั่งเฉพาะทาง

![ภาพที่ 4.2 การเขียนโปรแกรมเคลื่อนที่ต่อเนื่องหลายจุดด้วยคำสั่ง MVS ต่อกัน](/images/book/image28.png)

### 4.1.3 การปรับทิศทางปลายแขนด้วยเวกเตอร์การหมุน (Orientation Vector)

นอกจากตำแหน่ง (Position) แล้ว การเคลื่อนที่แบบต่อเนื่องในหลายงาน เช่น
การเชื่อมหรือการพ่นสี ยังต้องควบคุมทิศทาง (Orientation) ของปลายแขน
ให้เหมาะสมกับผิวชิ้นงานตลอดเส้นทางด้วย ภาษาโปรแกรมจึงมีเวกเตอร์การหมุน (Orientation
Vector) เช่น VCER สำหรับปรับมุม Roll/Pitch/Yaw ของปลายแขนโดยไม่เปลี่ยนตำแหน่ง
(X, Y, Z) เมื่อนำเวกเตอร์การหมุนไปบวกกับตำแหน่งเดิม (เช่น NEW_VECR = NEW_POS +
VCER) จะได้ตำแหน่งใหม่ ที่มีทั้งพิกัดตำแหน่งเดิมและมุมทิศทางที่เปลี่ยนไปตามที่กำหนด
หลักการนี้สำคัญมากในงานเชื่อมที่ต้องรักษามุมหัวเชื่อมให้ตั้งฉากกับตะเข็บเสมอ
แม้ว่าตะเข็บนั้นจะมีความโค้งเปลี่ยนแปลงไปตลอดเส้นทางก็ตาม

![ภาพที่ 4.3 การปรับทิศทางปลายแขนด้วยเวกเตอร์การหมุน (Orientation Vector)](/images/book/image29.png)

### 4.1.4 การโปรแกรมตำแหน่งด้วยตัวแปรเวกเตอร์ (Vector Function Programming)

แทนที่จะกำหนดตำแหน่งใหม่ทุกจุดด้วยการสอนงาน (Teaching) ทีละตำแหน่ง
ภาษาโปรแกรมหุ่นยนต์อุตสาหกรรมมีฟังก์ชันเวกเตอร์ตำแหน่ง (Vector Function)
ที่ช่วยคำนวณตำแหน่งใหม่จากตำแหน่งเดิมบวกกับค่าออฟเซ็ต (Offset) ที่กำหนด เช่น คำสั่ง DEF
POS ใช้ประกาศตัวแปรตำแหน่ง แล้วกำหนดค่าเวกเตอร์ เช่น VECZ100
แทนการเลื่อนตำแหน่งตามแกน Z ระยะ 100 หน่วย หรือ VECXYZ
แทนการเลื่อนตำแหน่งตามแนวทแยงทั้งสามแกน เมื่อนำเวกเตอร์เหล่านี้มาบวกกับตำแหน่ง อ้างอิง
(เช่น NEW_POS = P99 + VECZ100) จะได้ตำแหน่งใหม่โดยไม่ต้องสอนงานซ้ำ
วิธีนี้มีประโยชน์มากในการสร้างเส้นทางต่อเนื่องที่มีรูปแบบซ้ำ ๆ
หรือต้องปรับตำแหน่งสัมพัทธ์จากจุดอ้างอิงเดิม

![ภาพที่ 4.4 การโปรแกรมตำแหน่งด้วยตัวแปรเวกเตอร์ (Vector Function Programming)](/images/book/image30.png)

### 4.2.1 งานเขียนโปรแกรมเคลื่อนที่แบบจุดต่อจุด (PTP)

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถสังเกตการเขียนโปรแกรมเคลื่อนที่แบบจุดต่อจุด (PTP)
ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 4.1
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง การต่อวงจรมีขั้นตอนดังนี้

แล้วต่อท่อนแขนเข้ากับแขนหมุนของเซอร์โว 1

แล้วต่อท่อนแขนที่สองเข้ากับแขนหมุนของเซอร์โว 2

### 4.2.2 งานเขียนโปรแกรมเคลื่อนที่แบบต่อเนื่อง (CP) และเปรียบเทียบผล

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว ผู้เรียนสามารถดำเนินการเขียนโปรแกรมเคลื่อนที่แบบต่อเนื่อง (CP)
และเปรียบเทียบผลการเคลื่อนที่ได้ถูกต้อง โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 4.1
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง โดยคัดลอกโค้ดตามตารางที่ 4.1
ลงในไฟล์ main.py แล้วอัปโหลดไปยังบอร์ด ESP32 จากนั้นทดลองตามขั้นตอนต่อไปนี้

ตารางที่ 4.1 โค้ดภาษา
MicroPython สำหรับการเปรียบเทียบการเคลื่อนที่แบบจุดต่อจุดกับแบบต่อเนื่อง

| \# main.py -- ESP32 MicroPython: PTP vs Continuous Path (CP) demo, 2-DOF arm |
|------------------------------------------------------------------------------|
| from machine import Pin, PWM                                                 |
| import time                                                                  |
| servo1 = PWM(Pin(18), freq=50) \# Joint 1                                    |
| servo2 = PWM(Pin(19), freq=50) \# Joint 2                                    |
|                                                                              |
| def set_angle(servo, angle):                                                 |
| duty = int(1638 + (angle / 180) \* (8192 - 1638))                            |
| servo.duty_u16(duty)                                                         |
|                                                                              |
| waypoints = \[(0, 90), (45, 60), (90, 30), (135, 60), (180, 90)\]            |
|                                                                              |
| def move_ptp(theta1, theta2):                                                |
| \# กระโดดตรงไปตำแหน่งเป้าหมายทันที (จำลอง Point-to-Point)                        |
| set_angle(servo1, theta1)                                                    |
| set_angle(servo2, theta2)                                                    |
| time.sleep(0.8) \# หยุดสั้น ๆ ที่แต่ละจุด                                           |
|                                                                              |
| def move_cp(theta1_start, theta2_start, theta1_end, theta2_end, steps=20):   |
| \# ขยับทีละองศาผ่านจุดกลาง ไม่หยุดระหว่างทาง (จำลอง Continuous Path)                |
| for i in range(steps + 1):                                                   |
| t1 = theta1_start + (theta1_end - theta1_start) \* i / steps                 |
| t2 = theta2_start + (theta2_end - theta2_start) \* i / steps                 |
| set_angle(servo1, t1)                                                        |
| set_angle(servo2, t2)                                                        |
| time.sleep(0.03) \# ไม่มีการหยุดสนิทระหว่างจุด                                     |
|                                                                              |
| print('=== โหมด PTP (กระโดดตรงไปแต่ละจุด) ===')                                |
| for th1, th2 in waypoints:                                                   |
| move_ptp(th1, th2)                                                           |
|                                                                              |
| time.sleep(2.0)                                                              |
|                                                                              |
| print('=== โหมด CP (เคลื่อนที่ต่อเนื่องผ่านทุกจุด) ===')                               |
| for i in range(len(waypoints) - 1):                                          |
| t1a, t2a = waypoints\[i\]                                                    |
| t1b, t2b = waypoints\[i + 1\]                                                |
| move_cp(t1a, t2a, t1b, t2b)                                                  |

1\. เปิดโปรแกรม Visual Studio Code เชื่อมต่อ ESP32 ผ่าน USB แล้วอัปโหลดไฟล์
main.py ตามตารางที่ 4.1

2\. สังเกตการเคลื่อนที่ของแขนกลในโหมด PTP (ช่วงแรก) ว่ามีลักษณะกระตุกหรือหยุดสั้น ๆ
ที่แต่ละตำแหน่งหรือไม่

3\. สังเกตการเคลื่อนที่ของแขนกลในโหมด CP (ช่วงหลัง) ว่ามีลักษณะราบรื่นต่อเนื่องกว่าโหมด
PTP หรือไม่

4\. บันทึกลักษณะการเคลื่อนที่ที่สังเกตได้ของทั้งสองโหมดลงในแบบบันทึกผลการปฏิบัติงาน

ให้วิเคราะห์ว่าค่า steps และ time.sleep ในฟังก์ชัน move_cp
มีผลต่อความราบรื่นของการเคลื่อนที่อย่างไร และอธิบายว่าเหตุใดการเพิ่มจำนวน steps
จึงทำให้เส้นทางใกล้เคียงกับการเคลื่อนที่แบบต่อเนื่องในหุ่นยนต์อุตสาหกรรมจริงมากขึ้น

## 4.3 การเขียนโปรแกรมแบบพาเลทและการควบคุมจังหวะเวลา

### 4.3.1 การเขียนโปรแกรมแบบพาเลท (Pallet Programming)

เมื่อหุ่นยนต์ต้องทำงานซ้ำในตำแหน่งที่จัดเรียงเป็นระเบียบ เช่น
การวางชิ้นงานลงในถาดหรือพาเลทที่มีหลายแถวหลายคอลัมน์ การเขียนโปรแกรมกำหนด
ตำแหน่งทีละจุดจะไม่มีประสิทธิภาพ จึงนิยมใช้ฟังก์ชันพาเลท (Pallet Function) โดยคำสั่ง
DEF PLT(หมายเลขพาเลท),(จุดเริ่มต้น),(จุดปลาย A),(จุดปลาย
B),(จุดทแยงมุม),(จำนวนแถว A),(จำนวนแถว B),(ทิศทาง)
จะคำนวณตำแหน่งของทุกช่องในพาเลทให้อัตโนมัติจากมุมอ้างอิงทั้งสี่จุด รูปแบบทิศทางการเดินมี 2
แบบหลัก คือ แบบสลับฟันปลา (Zig-Zag)
ซึ่งสลับทิศทางเดินในแต่ละแถวเพื่อลดระยะทางเคลื่อนที่รวม และแบบทิศทางเดียวกัน (Same
Direction) ซึ่งเดินทิศทางเดียวกันซ้ำทุกแถว
เหมาะกับงานที่ต้องการทิศทางเข้าจับชิ้นงานคงที่เสมอ

### 4.3.2 การใช้ลูป FOR...NEXT ร่วมกับตำแหน่งพาเลท

เมื่อกำหนดฟังก์ชันพาเลทด้วยคำสั่ง DEF PLT แล้ว สามารถคำนวณตำแหน่งแต่ละช่องได้ด้วยฟังก์ชัน
PLT(หมายเลข, ลำดับที่) ซึ่งเมื่อรวมกับลูป FOR...NEXT
จะทำให้หุ่นยนต์เคลื่อนที่ไปยังทุกตำแหน่งในพาเลทได้โดยอัตโนมัติโดยไม่ต้องเขียนคำสั่งตำแหน่งซ้ำทีละจุด
ตัวอย่างเช่น FOR Place_POS = 1 TO 8 กำหนดให้ตัวแปร Place_POS วนค่าตั้งแต่ 1 ถึง 8
ในแต่ละรอบจะคำนวณตำแหน่งจริงด้วย POS_Pallet = PLT 1, Place_POS
แล้วสั่งให้หุ่นยนต์เคลื่อนที่เข้าใกล้ วางชิ้นงาน และถอยกลับ
ก่อนวนไปคำนวณตำแหน่งถัดไปด้วยคำสั่ง NEXT Place_POS จนครบทุกตำแหน่งที่กำหนด
วิธีนี้ทำให้โปรแกรมกระชับและแก้ไขจำนวนตำแหน่งได้ง่ายเพียงเปลี่ยนค่าพารามิเตอร์ของ DEF
PLT เท่านั้น

### 4.3.3 การควบคุมความเร็วและจังหวะเวลาในเส้นทางต่อเนื่อง

ความเร็วของหุ่นยนต์มีผลโดยตรงต่อคุณภาพของเส้นทางต่อเนื่อง
โดยเฉพาะในช่วงที่เส้นทางมีความโค้งมาก การกำหนดความเร็วสูงเกินไปอาจทำให้ระบบควบคุม
ไม่สามารถคำนวณ Blending ได้ทันเวลา
ส่งผลให้เส้นทางจริงเบี่ยงเบนไปจากเส้นทางที่โปรแกรมไว้ (Overshoot)
จึงนิยมปรับค่าความเร็วโดยรวม (OVRD) ให้ต่ำลงในช่วงที่มีความโค้งมาก
และเพิ่มความเร็วในช่วงเส้นทางตรงเพื่อประหยัดเวลาการทำงานโดยรวม
นอกจากนี้การหน่วงเวลา (DLY) ควรใช้เท่าที่จำเป็น เท่านั้น
เนื่องจากการแทรกคำสั่งหน่วงเวลาระหว่างจุดจะทำให้หุ่นยนต์หยุดสนิท
ซึ่งขัดกับหลักการเคลื่อนที่แบบต่อเนื่อง ควรใช้เฉพาะที่จุดเริ่มต้น หรือจุดสิ้นสุดของงานเท่านั้น

## 4.4 การเขียนโปรแกรมจัดเรียงชิ้นงานแบบพาเลท

หัวข้อนี้เป็นการฝึกปฏิบัติตามใบงานปฏิบัติหน่วยเรียนที่ 4.2
เรื่องการเขียนโปรแกรมจัดเรียงชิ้นงานแบบพาเลท ใช้เวลา 2 ชั่วโมง (120 นาที)
ผู้เรียนนำความรู้จากหัวข้อที่ผ่านมามาปฏิบัติงานจริง และบันทึกผลลงในแบบบันทึกผลการปฏิบัติงาน
โดยมีลำดับขั้นการปฏิบัติงานดังนี้

ขั้นที่ 1 รับชุดฝึก ตรวจความพร้อมของอุปกรณ์ตามรายการ
และอ่านข้อควรระวังด้านความปลอดภัยร่วมกับครูผู้สอน (10 นาที)

ขั้นที่ 2 วางกระดาษตารางพาเลทขนาด 2 แถว × 3 คอลัมน์ ระยะห่างระหว่างช่อง 3 ซม.
และกำหนดจุดอ้างอิงของช่องแรก (10 นาที)

ขั้นที่ 3 คำนวณพิกัด (x, y) ของทุกช่องจากจุดอ้างอิงและระยะห่าง
แล้วคำนวณมุมข้อต่อด้วยจลนศาสตร์ผกผัน (25 นาที)

ขั้นที่ 4 เขียนโปรแกรมลูป for ซ้อนกันเพื่อสั่งแขนกลเคลื่อนที่ไปยังแต่ละช่องตามลำดับ (25 นาที)

ขั้นที่ 5 ให้ครูตรวจโปรแกรม แล้วรันโปรแกรม วัดความคลาดเคลื่อนของตำแหน่งแต่ละช่อง
และจับเวลารอบการทำงาน (25 นาที)

ขั้นที่ 6 วิเคราะห์ผลการทดลองและตอบคำถามท้ายใบงาน (15 นาที)

ขั้นที่ 7 สรุปผล ส่งแบบบันทึกผล ถอดสายและเก็บอุปกรณ์ และทำความสะอาดพื้นที่ปฏิบัติงาน (10
นาที)

### 4.4.1 งานคำนวณพิกัดตำแหน่งช่องพาเลท

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว
ผู้เรียนสามารถสังเกตหลักการคำนวณพิกัดตำแหน่งช่องพาเลทแบบตารางได้ถูกต้อง
โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 4.2
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

พิกัดของช่องพาเลทแถวที่ i และคอลัมน์ที่ j (เริ่มนับจาก 0) คำนวณได้จาก x = x0 + j·dx
และ y = y0 + i·dy โดย (x0, y0) คือพิกัดของช่องแรกที่ใช้เป็นจุดอ้างอิง และ dx, dy
คือระยะห่างระหว่างช่องในแนวคอลัมน์และแนวแถว
เมื่อได้พิกัดของแต่ละช่องแล้วจึงนำไปคำนวณมุมข้อต่อด้วยจลนศาสตร์ผกผันของแขนกล 2-DOF

### 4.4.2 งานเขียนโปรแกรมลูปเคลื่อนที่ไปยังตำแหน่งพาเลท

เมื่อปฏิบัติงานในหัวข้อนี้แล้ว
ผู้เรียนสามารถดำเนินการเขียนโปรแกรมลูปเคลื่อนที่ไปยังตำแหน่งพาเลทได้ถูกต้อง
โดยปฏิบัติตามลำดับขั้นในใบงานปฏิบัติหน่วยเรียนที่ 4.2
และให้ครูผู้สอนตรวจสอบก่อนจ่ายไฟหรือสั่งงานระบบทุกครั้ง

การเขียนโปรแกรมใช้ลูป for ซ้อนกัน 2 ชั้น ลูปนอกนับแถว ลูปในนับคอลัมน์
ภายในลูปคำนวณพิกัดและมุมข้อต่อ แล้วสั่งมอเตอร์เซอร์โวเคลื่อนที่ไปยังตำแหน่งนั้น
พร้อมหน่วงเวลาให้แขนกลหยุดนิ่งก่อนเคลื่อนที่ไปยังช่องถัดไป ซึ่งเทียบได้กับการใช้คำสั่ง
FOR...NEXT ร่วมกับตำแหน่งพาเลทในหุ่นยนต์อุตสาหกรรม

## บทสรุป

การควบคุมแบบต่อเนื่องทำให้ปลายแขนหุ่นยนต์เคลื่อนที่ตามเส้นทางที่กำหนดอย่างราบรื่น
โดยใช้คำสั่งเคลื่อนที่แบบเส้นตรงต่อกันหลายจุด ตัวแปรเวกเตอร์สำหรับกำหนดตำแหน่ง

</details>

**6. เพราะเหตุใดรูปแบบ Zig-Zag จึงมักใช้ระยะทางการเคลื่อนที่รวมน้อยกว่ารูปแบบ Same Direction ในการจัดเรียงพาเลทที่มีหลายแถว**

<details><summary>เฉลย</summary>

Direction ในการจัดเรียงพาเลทที่มีหลายแถว

เพราะ Zig-Zag สลับทิศทางเดินในแต่ละแถว
ทำให้จุดสุดท้ายของแถวหนึ่งอยู่ใกล้กับจุดเริ่มต้นของแถวถัดไป ในขณะที่ Same Direction
ต้องเคลื่อนที่ย้อนกลับไปจุดเริ่มต้นของแถวใหม่ทุกครั้ง ทำให้มีระยะทางเคลื่อนที่รวมมากกว่า

</details>

**7. จงอธิบายว่าตัวแปร Place_POS ในผังงาน FOR Place_POS = 1 TO 8 ... NEXT Place_POS มีการเปลี่ยนแปลงค่าอย่างไรตลอดการทำงานของลูป**

<details><summary>เฉลย</summary>

Place_POS มีการเปลี่ยนแปลงค่าอย่างไรตลอดการทำงานของลูป

ตัวแปร Place_POS เริ่มต้นที่ค่า 1
แล้วใช้คำนวณตำแหน่งด้วยฟังก์ชันพาเลทและสั่งให้หุ่นยนต์เคลื่อนที่ในแต่ละรอบ เมื่อถึงคำสั่ง NEXT
Place_POS ค่าจะเพิ่มขึ้นทีละ 1 แล้ววนกลับไปตรวจสอบเงื่อนไขที่ FOR อีกครั้ง ทำซ้ำจนกระทั่ง
Place_POS มีค่าเท่ากับ 8 จึงสิ้นสุดการวนลูป

</details>

**8. เพราะเหตุใดจึงควรลดค่า OVRD ในช่วงเส้นทางที่มีความโค้งมาก แต่เพิ่มค่า OVRD ในช่วงเส้นทางตรง**

<details><summary>เฉลย</summary>

ในช่วงเส้นทางตรง

เพราะในช่วงที่เส้นทางโค้งมาก ความเร็วสูงอาจทำให้ตัวควบคุมคำนวณ Blending ไม่ทันเวลา
ทำให้เส้นทางจริงเบี่ยงเบนจากที่โปรแกรมไว้ (Overshoot)
การลดความเร็วช่วยรักษาความแม่นยำของเส้นทางในช่วงโค้ง
ส่วนช่วงเส้นทางตรงสามารถเพิ่มความเร็วได้โดยไม่กระทบความแม่นยำ
ช่วยประหยัดเวลาการทำงานโดยรวม

</details>

**9. จงอธิบายความแตกต่างระหว่างการเคลื่อนที่แบบจุดต่อจุด (PTP) และแบบต่อเนื่อง (CP)**

<details><summary>เฉลย</summary>

การเคลื่อนที่แบบจุดต่อจุดกำหนดเฉพาะตำแหน่งปลายทาง โดยไม่ควบคุมเส้นทางระหว่างจุด
เหมาะกับงานหยิบวางชิ้นงาน
ส่วนการเคลื่อนที่แบบต่อเนื่องควบคุมให้ปลายแขนเคลื่อนที่ตามเส้นทางที่กำหนด เช่น
เส้นตรงหรือเส้นโค้ง ด้วยความเร็วสม่ำเสมอ เหมาะกับงานเชื่อม งานพ่นสี และงานทากาว

</details>

**10. พาเลทขนาด 3 แถว × 4 คอลัมน์ มีระยะห่างระหว่างช่อง 50 มม. ทั้งสองแนว และช่องแรกอยู่ที่พิกัด (200, 100) มม. จงคำนวณพิกัดของช่องแถวที่ 3 คอลัมน์ที่ 4**

<details><summary>เฉลย</summary>

และช่องแรกอยู่ที่พิกัด (200, 100) มม. จงคำนวณพิกัดของช่องแถวที่ 3 คอลัมน์ที่ 4
